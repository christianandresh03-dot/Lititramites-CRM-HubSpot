# Lititramites-CRM-HubSpot
Proyecto de grado - Sistema de automatización CRM basado en HubSpot para gestión de trámites judiciales
## Descripción
Sistema de automatización CRM basado en HubSpot, integrado vía API 
con la plataforma SaaS de gestión judicial Lititrámites, para la 
administración de trámites y facturación en una empresa del sector 
legaltech.

## Autor
Christian Andrés Hernández Franco
Ingeniería de Sistemas - UNAD
Proyecto de Grado 2026

## Objetivo
Centralizar la gestión de trámites judiciales eliminando el uso de 
herramientas dispersas (Excel, WhatsApp, llamadas) mediante la 
implementación de pipelines, workflows de SLA, formularios embebidos 
e integración bidireccional entre HubSpot y Lititrámites.

## Estructura del repositorio
- /docs — Documento maestro del proyecto
- /evidencias — Capturas del sistema funcional
- /configuracion — Descripción técnica de la configuración

## Tecnologías utilizadas
- HubSpot CRM (Service Hub)
- API REST (Private App HubSpot)
- Webhooks bidireccionales
- Plataforma SaaS Lititrámites
